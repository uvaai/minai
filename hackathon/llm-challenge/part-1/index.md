
## LLM challenge: Hack the agent

The link to start this challenge is

[Hack the Agent](https://hacktheagent.com/register)

Register an account to start the challenge. **Note:** You do *not* need use a real email address or provide your social media for this.
Just make sure you remember the email and password for you team, so you can login at the next step.

You can chat with the agent for this challenge in the window on the right, using the text box at the bottom with the *Exec* button.
The challenge description is on the left side of the page. Each of the 5 challenges has a description of specific thing you should get
the agent to do or give you, that the agent is not allowed to do according to its instructions. For each challenge this will correspond
to some special string of characters, called a *flag*, that should look something `Ethiack{???????}`. You can submit the flag to
check your solution, and if it is correct, you'll move to the next challenge!
