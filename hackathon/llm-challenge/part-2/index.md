
## LLM challenge: Lakera Agent Breaker

The link to start this challenge is

[Lakera Agent Breaker](https://play.lakera.ai/agent-breaker)

At the bottom of the page is a list of 10 different challenges, and each of these challenges has
several levels that get increasingly harder. You can start whichever challenge your team finds
the most interesting. Note that some challenges require some addition technical background to
understand the full context, so if you're not sure how to proceed, you can always switch to a
different challenge.

At the end we'll come by and count the points for each team. Each level on a challenge gets
increasingly harder, so the later levels will be worth more points. The first level of each
challenge is worth 1 point, the second level is worth 2 points, and so on. For each of the
10 challenges of the Agent Breaker, and also the original Hack the Agent challenge, you team
gets the following points per challenge:

* Level 1 completed: 1 point
* Level 2 completed: 3 points
* Level 3 completed: 6 points
* Level 4 completed: 10 points
* Level 5 completed: 15 points

The score for your team will be the sum of the points for all of the 11 challenges.
